# Bravura Text 使用简介

*版本 1.1，2015 年 10 月 30 日*

Bravura Text 是一款符合 [SMuFL] [1] 规范的音乐符号字体，适用于文本类应用，如文字处理器、文本编辑器、桌面出版软件，也可用于网页。

Bravura Text 采用 [SIL 开放字体许可证] [2] 授权，允许自由使用、重新分发和修改，但请遵守许可证中的条件。

## 字符集
Bravura Text 是 SMuFL（标准音乐字体布局）的参考实现，因此包含 SMuFL 规范中定义的所有符号。[下载 SMuFL 规范] [3] 可获取 Bravura Text 中所有符号的完整列表，包括描述和码位。

SMuFL 使用 Unicode 基本多文种平面的私有用例区（U+E000 至 U+FFFF）对所有符号进行编码。这意味着无法直接通过键盘上的字母数字键输入这些符号。

## Unicode 输入设置
关于如何在所有操作系统上启用 Unicode 输入的详细说明超出了本文档的范围。SIL 提供了[一个优秀的页面] [4]，包含 Windows、OS X 和 Linux 的相关信息和工具链接。本文档包含一些基本说明，但你可能需要参考其他资源以获取针对你的操作系统和应用程序的帮助。

### Windows
在 Windows 上有多种输入 Unicode 字符的方法。可以尝试以下三种方法：

#### 方法一：十六进制输入后按 `Alt`
在 Windows 中，某些应用程序（如 Microsoft Word（Microsoft Office 套件的一部分）和 WordPad（每个 Windows 安装都附带））支持将输入的字母数字序列转换为单个 Unicode 字符。

Bravura Text 中 G（高音）谱号的 Unicode 码位是 U+E050，这是一个十六进制数（十进制为 57424）。要在 Word 或 WordPad 中输入该字符，请键入 `E050`，然后按 `Alt+X`（按住 `Alt` 键，然后按 `X` 键）。键入的字符 **E050** 将被替换为单个字符，该字符可能显示为空矩形或带有 **?** 的矩形。选中该字符并将字体更改为 Bravura Text，G 谱号就会出现。

虽然 Unicode 码位通常写作 U+E050 的形式，但在使用本方法和下一种方法输入码位时，可以忽略 "U+" 部分。

#### 方法二：`Alt` + 十六进制输入
如果你使用的应用程序不支持上述转换方式，可以通过以下方式启用 Unicode 输入：按住 `Alt`，然后在**数字键盘**上键入 `+`，接着在数字键盘上键入十六进制数字，最后松开 `Alt`。例如，要输入 G 谱号（U+E050），按住 `Alt`，在数字键盘上键入 `+`，然后键入 `E050`，再松开 `Alt`。同样，如果未选择 Bravura Text 字体，可能会看到空矩形或带有 **?** 的矩形。选中该字符并更改字体为 Bravura Text，G 谱号就会出现。

#### 方法三：字符映射表
内置的字符映射表应用程序可以将任何 Unicode 字符复制到系统剪贴板，以便粘贴到其他应用程序中。要运行字符映射表，请单击 `开始` 按钮或按键盘上的 `Windows` 键，然后键入 `charmap` 并按 `Return`。字符映射表将运行。

在字符映射表中，从窗口顶部的 **字体** 菜单中选择 **Bravura Text**。打开窗口底部的 **高级视图** 复选框，将显示额外选项。从 **字符集** 菜单中选择 **Unicode**，然后从 **分组依据** 菜单底部选择 **Unicode 子范围**。将弹出一个名为 **分组依据** 的窗口，显示 Unicode 子范围列表；从列表底部选择 **私有用例字符**。（之后可以根据需要关闭 **分组依据** 窗口。）

现在，字符映射表窗口主区域的网格将显示 Bravura Text 中的所有符号（不幸的是，无法放大显示，因此它们看起来相当小）。找到所需字符后，用鼠标选中并单击 **选择** 或双击它，该字符将被添加到 **待复制字符** 编辑控件中。单击 **复制** 将 **待复制字符** 中的内容复制到剪贴板，然后切换到要粘贴文本的应用程序，选择 `编辑` ▸ `粘贴` 或键入 `Ctrl+V`。

#### 其他方法
你可以尝试使用第三方实用程序来帮助查找和插入 Unicode 字符。列出这些免费实用程序并不意味着推荐或保证，你可以自行承担尝试风险：

* [CatchChar] [5] 允许你将常用 Unicode 字符添加到一个菜单中，通过键盘快捷键在任何应用程序中触发。
* [BabelMap] [6] 是 Windows 内置字符映射表应用程序的高级替代品。
* 还有其他商业（非免费）实用程序，包括 [PopChar] [7]。

### OS X
对于运行 OS X 的 Mac 电脑，插入任意 Unicode 字符的最简单方法是使用提供的 Unicode 十六进制输入法。启用方法如下：

* 在系统偏好设置中，选择 **键盘**。
* 在 **键盘** 选项卡上，打开 **在菜单栏中显示“键盘与字符显示程序”**。打开后，菜单栏中 Spotlight 图标的左侧会出现一个对应于你键盘正常语言/布局的国旗图标。
* 在 **输入源** 选项卡上，单击 **+**，在弹出的表单中，在左侧列表中选择 **其他**，然后在右侧列表中选择 **Unicode 十六进制输入**，然后单击 **添加** 关闭表单。
* 确保 **在菜单栏中显示输入菜单** 已打开，然后关闭系统偏好设置。

Unicode 十六进制输入法在大多数 OS X 应用程序中都能使用。例如，要在 TextEdit 中试用，请打开一个新的文本文档。Bravura Text 默认不会出现在 TextEdit 工具栏的字体菜单中，因为它不是英文语言字体，所以要选择 Bravura Text，必须通过选择 `格式` ▸ `字体` ▸ `显示字体` 或键入 `⌘T` 来显示字体面板。在字体面板中，在 **集合** 下选择 **所有字体**，然后在 **系列** 下选择 **Bravura Text**，然后关闭字体面板（再次键入 `⌘T`）。

现在 Bravura Text 已成为所选字体（并会出现在此文档的 TextEdit 工具栏字体菜单中）。要输入码位为 U+E050 的 G（高音）谱号，首先从菜单栏的输入菜单中选择 **Unicode 十六进制输入** 输入法。现在按住 `Alt` 并键入 `E050`（不要键入 "U+" 前缀），然后松开 `Alt`。

如果你想在普通语言输入法和 Unicode 十六进制输入法之间快速切换，可以在系统偏好设置的 **键盘** 面板中分配系统键盘快捷键。选择 **快捷键** 选项卡，然后在左侧列表中选择 **输入源**。打开 **选择上一个输入源** 和/或 **选择下一个输入源** 的复选框，并分配键盘快捷键。OS X 建议的默认快捷键通常被 Spotlight 占用，因此你可能需要分配其他快捷键，例如 `^Space`（`^` 对应 `Ctrl` 键）。

## Bravura Text 使用说明

### 缩放比例
Bravura Text 的缩放比例使得五线谱（如 U+E014）的高度与同字号常规文本字体中大写字母的高度大致相同。它既可用于行内（即在同字号文本中间），也可单独使用（通常使用较大的字号）。因此，Bravura Text 中的所有符号都经过适当缩放，以便在五线谱上以正确大小绘制。

一个例外是用于力度记号的粗斜体字母，它们的缩放比例使得它们与同字号常规文本字体中小写字母的大小大致相同。

### 零宽度字符
Bravura Text 中表示谱表和谱线的符号宽度为零。这是为了允许其他音乐符号打印在它们上面。

谱线符号提供三种宽度：窄（一个空格的宽度）；正常（两个空格的宽度）；宽（三个空格的宽度）。

空格是处理印刷音乐符号时常用的计量单位。一个空格是两条谱线中线之间的垂直距离；因此，五线谱的高度为四个空格。

拍号数字的宽度也为零，以便将它们上下堆叠放置。加线符号的宽度同样为零。

所有其他字形的两侧边距为零，即每个字形的推进宽度恰好等于其符号的边界框。

### 空格字符
要在符号之间插入空格，请使用以下按键：

* 键入 `Space`（空格）将输入位置向前移动半个空格。
* 键入 `-`（连字符）将输入位置向前移动一个空格。
* 键入 `=`（等号）将输入位置向前移动两个空格。

### 默认垂直位置
Bravura Text 中的许多字形提供多个垂直位置，以便它们可以出现在不同的谱线位置上。除常用谱号外，所有可以在不同垂直位置绘制的字形默认都定位在五线谱字形（如 U+E014）的中间线上。常用谱号的默认位置如下：

* G 谱号（如 U+E050）：如高音谱号，即下环底部与最下面一条谱线对齐。
* F 谱号（如 U+E061）：如低音谱号，即两个点位于从上往下第二条谱线的两侧。
* C 谱号（如 U+E058）：如中音谱号，即谱号中心位于中间谱线上。

以下字形范围（如 SMuFL 规范所定义）可以在谱表上移动到不同的垂直位置：

* 加线（在 **谱表** 范围内）
* 所有符头（在 **符头**、**斜线符头**、**圆形和方形符头**、**音簇**、**音名字母符头** 范围内）
* 带符干和符尾的预组合音符（在 **单独音符** 和 **符杠组合音符组** 范围内）
* 预组合符干（在 **符干** 范围内）
* 符尾（在 **符尾** 范围内）
* 所有临时记号（在 **标准临时记号**、**Gould 箭头四分之一音临时记号**、**Stein-Zimmermann 临时记号**、**扩展 Stein-Zimmermann 临时记号**、**Sims 临时记号**、**Johnston 纯律临时记号**、**扩展 Helmholtz-Ellis JI 临时记号**、所有 Sagittal 范围、**Wyschnegradsky 临时记号**、**Arel-Ezgi-Uzdilek (AEU) 临时记号**、**土耳其民间音乐临时记号**、**波斯临时记号**、**其他临时记号** 范围内）
* 演奏法记号（在 **演奏法记号** 范围内）
* 延长记号、休止符、呼吸记号（在 **停顿与休止** 范围内）
* 休止符（在 **休止符** 范围内）
* 1、2 和 4 小节反复记号（在 **小节反复** 范围内）
* 中世纪和文艺复兴谱号、节拍和量度记号、符头和符干、单独音符、单音和多音素 chant 形式、chant 演奏法记号和临时记号（在 **中世纪和文艺复兴...** 范围内）
* **基辅方形记谱法**

### 改变垂直位置
Bravura Text 使用 OpenType 连字来修改符号的默认垂直位置。在 OpenType 字体中，连字是一种字形替换，其中两个或多个字形被替换为另一个单独的字形。这在文本字体中通常用于产生特定字母组合（如 "fi" 或 "fl"）的优雅外观。

在 Bravura Text 中，连字用于调整单个符号的垂直位置。首先，输入与要改变垂直位置的幅度相对应的码位，然后输入符号本身的码位。只要你使用的应用程序支持 OpenType 连字，你就会看到符号出现在所需的垂直位置上。

用于升高或降低符号位置的码位如下（括号中的音名对应于带有高音谱号的五线谱；可移动符号的默认垂直位置为 B4）：

* 升高一个谱线位置（C5）：U+EB90
* 升高两个谱线位置（D5）：U+EB91
* 升高三个谱线位置（E5）：U+EB92
* 升高四个谱线位置（F5）：U+EB93
* 升高五个谱线位置（G5）：U+EB94
* 升高六个谱线位置（A5）：U+EB95
* 升高七个谱线位置（B5）：U+EB96
* 升高八个谱线位置（C6）：U+EB97
* 降低一个谱线位置（A4）：U+EB98
* 降低两个谱线位置（G4）：U+EB99
* 降低三个谱线位置（F4）：U+EB9A
* 降低四个谱线位置（E4）：U+EB9B
* 降低五个谱线位置（D4）：U+EB9C
* 降低六个谱线位置（C4）：U+EB9D
* 降低七个谱线位置（B3）：U+EB9E
* 降低八个谱线位置（A3）：U+EB9F

因此，例如要将一个黑色符头放在 G4 谱线位置上，你可以先输入 U+EB99（降低两个谱线位置），然后紧接着输入 U+E0A4（黑色符头）。

位于谱线之外的符头（即升高或降低六个或更多谱线位置）不会自动显示加线，因此必须单独添加加线，添加的加线应在符头**之前**（因为它们宽度为零），并且升高或降低相同的谱线位置数。

提供了特殊的码位用于将拍号数字移动到正确的垂直位置：

* 定位为分子（上方数字）：U+E09E
* 定位为分母（下方数字）：U+E09F

要输入 4/4 拍号，你可以先输入 U+E09E（定位为分子），紧接着输入 U+E084（拍号数字 4），然后输入 U+E09F（定位为分母），紧接着再输入 U+E084。最后，输入一个或多个空格来推进输入位置。
